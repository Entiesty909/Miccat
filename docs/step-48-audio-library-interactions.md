# Step 48 — 音频库管理与路由文件播放收口

范围：同一批收口音频库分类/条目管理、三栏布局与编辑、路由增益/峰值显示、播放设置位置及路由文件手动播放语义。真实数据和配置仍是权威；不改磁盘文件名，不伪装物理麦克风为 render 目标。

功能要求：
1. 分类/列表/详情三栏可调；列表只展示当前分类及后代，搜索/排序/分页索引一致；分类与条目名称/图标变更保存到 AppConfig。
2. 分类重命名/删除保持层级路径与图标映射；自定义图标、首字和默认音符使用既有原生文件选择/字体，不加入示例数据或依赖。
3. 播放页默认设备只用于新文件卡片；现有卡片的多目标 `file_output_ids` 独立保存。详情不再提供输出/文件音量/本机试听控制；禁用卡片设备不进入路由目标集合。
4. 文件源启用、路由启动和播放互不自动触发；未启用转发仍可本机播放、切歌、循环。关闭转发只停止该文件的路由槽，不中断本机试听；播放中启用/开始转发从当前进度接入。
5. 文件停止/未播放显示播放三角，播放显示暂停；真实峰值来源于 capture/SFX 采样，UI 不用音量值伪造 dB；总线增益 dB 与信号峰值 dBFS 分开。
本批音频库布局补充验收（2026-10-23）：
1. 分类图标与文字垂直居中，子分类按每级 10px 缩进；左右三栏之间只留 6px 可拖分隔条，左右栏可收起/展开并恢复原宽度，列表至少保留 350px。
2. 中间列表只展示图标、名称与时长，图文上下居中；分类/状态/快捷键列、行内播放与更多按钮不再占位。右键“添加到路由主页”把本页可见行映射到真实音频库索引，再沿用添加卡片回调。
3. 播放条移至三栏上方且常显，高度 44px，空闲时按钮/进度条禁用，播放中仍使用原有导航/暂停/停止回调。
本批三栏续验（2026-10-23）：分类栏收窄并减小子分类文字缩进；分隔线可把左栏或右栏拖至 0px，折叠箭头随状态反转并保留展开宽度。顶部播放条不再显示右侧“未播放”及曲名；详情栏移除循环播放、分类、本机试听及其说明；中间列表加入跨页连续序号，名称/时长表头分别切换排序字段和方向，移除独立“按名称”按钮。中间条目可拖放到左侧分类，桥接按当前过滤、排序和页码还原真实条目索引，并拒绝非法目标。
本批视觉补充验收（2026-10-23）：路由文件卡片与音频库顶部四个播放控制只保留可点击图标，不绘制按钮背景；顶部播放条贴住页面上边和左右边，高度 44px，四图标上下居中；三栏紧贴播放条，左分类侧栏底部不再显示快捷键/管理区块。
