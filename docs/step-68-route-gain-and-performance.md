# Step 68 — 路由增益显示与性能交互修正

范围：修正 Step 67 后发现的分隔条、滚动、分类层级、编辑保存和路由增益显示问题；添加源对话框改为进程/音频文件/麦克风三类真实入口。未新增依赖，未写入示例进程、音频或麦克风名称。

改动：

- 三栏分隔条方向修正：左右拖动分别改变分类栏和详情栏宽度，限制最小/最大值。
- 音频详情使用无可见滚动条的 `ScrollView`，仍保留鼠标滚轮滚动。
- 子分类图标按真实 `/` 层级缩进到名称前，不再固定在最左侧。
- 分类/条目编辑保存修正了 `RefCell` 借用生命周期，避免保存时闪退。
- 编辑图标不再使用默认图标下拉框；支持默认音乐音符、首字图标和自定义图标文件。
- 添加源对话框改为三类真实入口：进程列表、音频文件入口、麦克风设备；进程和麦克风均来自现有枚举模型。
- 路由源滑块显示当前增益 dB，总音量显示总线增益 dB；状态栏 Popover 显示进程/麦克风 capture 线程采样的实时峰值 dB，模型更新复用 `SourceRows::set_if_changed`，避免每 50ms 重建未变化的列表。

性能边界：

- Popover 的进程和麦克风峰值来自 capture 线程的无锁 `AtomicU32` 窗口采样；音频文件源在未接入独立 SFX 峰值采样时显示 `-∞ dB`，不使用音量值伪造信号峰值。
- 峰值采样只做 f32 遍历和原子写入，不在实时线程分配、加锁或写 UI；UI 每 50ms 读取并清零窗口。
- 图标文件只在编辑保存/列表模型刷新时读取，不在音频热路径读取。

```bat
scripts\\build-dev.cmd build
scripts\\build-dev.cmd test
scripts\\check.cmd
target\\debug\\miccat.exe --snapshot-ui --page player --out "%TEMP%\\miccat-step-68.raw"
```
